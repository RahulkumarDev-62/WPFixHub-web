# WPFixHub Deployment Guide

## Prerequisites
- Node.js >= 16.0.0
- npm >= 8.0.0
- Git
- Supabase account
- Payment gateway accounts (Razorpay/PhonePe)

## Environment Setup

### 1. Supabase Setup
1. Create a new Supabase project
2. Create tables according to the schema
3. Set up Row Level Security (RLS) policies
4. Get your API URL and anon key

### 2. Payment Gateway Setup
- **Razorpay**: Get API keys from dashboard
- **PhonePe**: Get merchant ID and API key

### 3. Google Gemini Setup
- Get API key from Google Cloud Console
- Enable Generative AI API
