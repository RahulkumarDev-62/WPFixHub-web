
# WPFixHub - Digital Marketing Agency Platform

A comprehensive web application for a professional WordPress fixes and digital marketing agency. Built with React, Supabase, and modern web technologies.

## 🚀 Features

### For Users
- **Service Ordering**: Browse and order services with detailed descriptions
- **Booking System**: Schedule service appointments with date/time selection
- **Appointment Scheduling**: Book consultations with the team
- **Payment Integration**: Secure payments via Razorpay and PhonePe
- **Invoice Management**: Download and manage invoices
- **Profile Management**: Update personal information and change password
- **Order Tracking**: Monitor order status in real-time
- **AI Assistant**: Get help from Gemini AI chatbot

### For Admins
- **Dashboard**: Overview of business metrics and statistics
- **Service Management**: Create, update, and delete services
- **Team Management**: Manage team members and their information
- **Order Management**: Track and update order statuses
- **Booking Management**: Manage service bookings
- **Appointment Management**: Handle appointment scheduling
- **Payment Tracking**: Monitor all transactions
- **User Management**: Manage user accounts
- **Invoice Management**: Generate and track invoices
- **Website Settings**: Configure business information and payment gateways

## 📋 Tech Stack

### Frontend
- **React 18.2.0** - UI library
- **React Router 6.16.0** - Client-side routing
- **Tailwind CSS 3.3.2** - Styling
- **Lucide React** - Icons
- **Axios** - HTTP client

### Backend & Database
- **Supabase** - Backend as a Service
- **PostgreSQL** - Database

### Payment Integration
- **Razorpay** - Payment gateway
- **PhonePe** - Payment gateway

### AI Integration
- **Google Gemini AI** - AI chatbot

### PDF Generation
- **jsPDF** - PDF generation
- **html2canvas** - HTML to canvas conversion

### Build Tools
- **Vite** - Build tool
- **ESLint** - Code linting
- **Prettier** - Code formatting

## 🛠️ Installation

### Prerequisites
- Node.js >= 16.0.0
- npm >= 8.0.0
- Supabase account
- Razorpay account (optional)
- PhonePe account (optional)
- Google Gemini API key (optional)
